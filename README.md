# opencode-kali

Run [opencode](https://opencode.ai) inside Kali Linux with **one command** — on Windows (WSL2), bare-metal, or in a VM — and get an offensive-security lab agent (`kali`) that drives the full Kali toolset: nmap, Metasploit, hashcat, gobuster, responder, and ~2,000 more packages.

**Full guide with all three single-command installs: [SETUP.md](SETUP.md)**
